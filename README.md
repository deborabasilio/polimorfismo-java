# Projeto de Programação Orientada a Objetos (POO) em Java

Este repositório contém os exercícios resolvidos para a disciplina de Programação Orientada a Objetos (MAPA), abordando os quatro pilares fundamentais da POO.

## 🚀 Conceitos Aplicados

O projeto está dividido em questões que demonstram a evolução técnica no aprendizado de Java:

1.  **Classes e Objetos (`Questao1.java`)**: Criação de classes, atributos e instanciamento de objetos.
2.  **Encapsulamento (`Questao2.java`)**: Uso de modificadores de acesso `private` e métodos `getters` e `setters` para proteção de dados.
3.  **Herança (`Questao3.java`)**: Criação de uma superclasse `Pessoa` para compartilhar atributos comuns entre `Aluno` e `Professor`.
4.  **Polimorfismo (`Questao4.java`)**: Sobrescrita de métodos (`@Override`) para que objetos da mesma superclasse se comportem de formas diferentes.
5.  **Interfaces (`Questao5.java`)**: Implementação de contratos de comportamento obrigatórios através de `interface`.

## 🛠️ Como Executar

Para compilar e executar qualquer uma das questões, utilize os comandos abaixo no terminal:

```bash
# Compilar
javac QuestaoX.java

# Executar
java QuestaoX
```
*(Troque o X pelo número da questão desejada)*
